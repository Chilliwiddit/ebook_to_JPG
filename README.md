# ebook_to_JPG
A simple script that converts ebooks into an ordered list of JPEGs, for use in various cases such as with [Mihon](https://github.com/mihonapp/mihon.git)

## How to set-up

1. Make sure Node is installed. You can install by going to their [website](https://nodejs.org/en/download).

2. Initialize the project

    `npm init -y`

3. Install the libraries

    `npm install pdf-lib pdf-poppler`

4. Install pdf-poppler. Refer to [this website](https://www.npmjs.com/package/pdf-poppler).
